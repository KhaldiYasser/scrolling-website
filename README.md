# 🌌 Nouvil Parallax Scrolling Web Project

A modern responsive web page demonstrating a multi-layered 2D **Parallax Scrolling Effect** using **HTML5**, **CSS3**, and **Vanilla JavaScript**. As the user scrolls down, different environmental layers (stars, moon, mountains, river, boat, and text) animate at varying speeds to create a depth perception[cite: 15, 16].

---

## 📸 Features

* **Multi-Layer Parallax Effect:** Elements move dynamically along the X and Y axes relative to the scroll position[cite: 15, 16].
* **Responsive Title Scaling:** The main title scales smoothly with scrolling and pins to a fixed position before reaching threshold visibility limits.
* **Dynamic Background Gradient:** Automatically transitions the main background gradient based on scroll depth[cite: 16, 17].
* **Sticky Navigation Bar:** Styled navigation header overlaying the hero section with active and hover states[cite: 15, 17].

---

## 🛠️ Built With

* **HTML5** - Page layout and element architecture.
* **CSS3** - Layout styling, positioning, blend modes, and CSS gradients[cite: 15, 17].
* **Vanilla JavaScript** - Scroll event listeners and inline dynamic style recalculation[cite: 15, 16].
